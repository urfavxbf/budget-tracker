# Budget Tracker

Native Android salary tracker and payday budget planner.

## Planned modules
- Daily time entries with time-in/time-out and multiple break intervals
- Salary calculation engine for regular pay, overtime, allowances, and deductions
- Payday cutoffs on the 15th and month-end
- Expenses, recurring bills, savings goals, and daily budget guidance
- Local persistence and Firebase-backed account/cloud sync
- Adaptive light/dark theme

Implementation is being built incrementally. Salary estimates are not the same as confirmed payroll payments; applicable payroll rules must be configured by the user.
